# Getting help

- **How do I…?** Start with the [docs](https://readme.niessen.dev/#/docs), especially [Getting started](https://readme.niessen.dev/#/docs) and the [FAQ](https://readme.niessen.dev/#/docs/faq), which covers broken images, permission errors and workflows that stop running.
- **Something is broken:** open a [bug report](https://github.com/DavidNiessen/readme-studio/issues/new?template=bug_report.yml) with your config (or a studio share link) and a link to the failing workflow run.
- **An idea for a widget or a preset:** open a [widget idea](https://github.com/DavidNiessen/readme-studio/issues/new?template=widget_request.yml).
- **A security problem:** follow [SECURITY.md](SECURITY.md) and report it privately.

This is a project maintained in spare time: answers usually come within a few days.
