# Code of conduct

Readme Studio follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind and respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment, insults and discrimination are not tolerated in issues, pull requests, discussions or anywhere else the project is represented.

## Reporting

If someone's behaviour worries you, contact the maintainer privately through [their GitHub profile](https://github.com/DavidNiessen) rather than in public. Reports are kept confidential and answered as soon as possible. The maintainer may remove comments, lock conversations or block people who break this code.
