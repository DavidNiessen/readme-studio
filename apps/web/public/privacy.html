Beim Aufruf der Website verarbeitet GitHub technisch notwendige Daten, insbesondere deine IP-Adresse, Datum und Uhrzeit des Abrufs, die aufgerufene Adresse, die übertragene Datenmenge, den Referrer und Angaben zu Browser und Betriebssystem, um die Seiten auszuliefern und den Dienst abzusichern. 4. Speicherung in deinem Browser

Das Studio und die Erweiterung speichern Folgendes ausschließlich auf deinem Gerät, im lokalen Speicher deines Browsers bzw. der Erweiterung:

  • Deine Designs, einschließlich ungespeicherter Änderungen je Repository.
  • Einstellungen, zum Beispiel helles oder dunkles Design, die zuletzt genutzte Editor-Ansicht, zuletzt verwendete Farben und die bevorzugte Speicherart.
  • Eine GitHub-Anmeldung, falls du sie angibst: ein von dir eingegebenes Personal Access Token oder, in der Erweiterung, das Token aus „Sign in with GitHub“. Es wird nur verwendet, um das README-Design in deinen Repositories zu lesen und zu speichern, und nur an GitHub (api.github.com) gesendet.
  • Eine ausstehende Änderung (nur Erweiterung): Beim Speichern über GitHubs eigenen Editor wird der Dateitext höchstens 15 Minuten gespeichert, damit die Erweiterung ihn in den Editor einfügen kann.

Diese Daten werden nicht an mich übertragen; ich kann sie weder einsehen noch auswerten. Das Speichern auf deinem Gerät ist unbedingt erforderlich, damit das Studio die von dir ausdrücklich gewünschten Funktionen bereitstellen kann (§ 25 Abs. 2 Nr. 2 TDDDG); eine Einwilligung ist dafür nicht nötig. Die Daten bleiben gespeichert, bis du sie löschst: durch Abmelden, durch Löschen der Website-Daten in deinem Browser oder durch Entfernen der Erweiterung.

Die Abrufe erfolgen nur, wenn du die jeweilige Funktion verwendest (Art. 6 Abs. 1 lit. f DSGVO; berechtigtes Interesse: die von dir angeforderte Funktion bereitzustellen).

  • Open-Meteo (api.open-meteo.com, geocoding-api.open-meteo.com): nur wenn du einen Ort suchst oder Widgets mit lokalem Wetter verwendest. Datenschutzhinweise

Einige dieser Anbieter sitzen außerhalb der EU, insbesondere in den USA.

Die Erweiterung läuft nur auf github.com. Sie kommuniziert ausschließlich mit GitHub, liest oder protokolliert nicht die Seiten, die du besuchst, und speichert ihre Daten wie in Abschnitt 4 beschrieben lokal, ohne Synchronisierung zwischen Geräten. Sie verwendet die Berechtigung storage für diese lokale Speicherung und Host-Berechtigungen für github.com, api.github.com und raw.githubusercontent.com.

7. GitHub Action

Die Action läuft in deinem eigenen GitHub-Repository auf Servern von GitHub, mit den Rechten, die du ihrem Workflow gibst. Sie liest öffentliche Daten zu deinem Konto oder Repository bei GitHub und den in Abschnitt 5 genannten Paketregistern, erzeugt die Bilder und schreibt sie und dein README in dein Repository. An mich wird dabei nichts übermittelt. Für die Verarbeitung durch GitHub gelten deine Vereinbarungen mit GitHub.

Privacy policy

English translation for information. The German version above is the legally binding one.

Readme Studio has no accounts, no servers of its own, no cookies, no analytics or tracking and no advertising. What you make stays in your browser and in your own GitHub repositories. This policy explains exactly what is stored where and which services your browser talks to.

1. Controller

David Nießen
Hämmerlingstraße 61E
12555 Berlin
Germany
Email: support@niessen.dev

This address is also the contact for all privacy requests. No data protection officer is appointed, and none is required by law.

2. Scope

This policy covers the website readme.niessen.dev (the studio and its documentation), the "Readme Studio" browser extension for Chrome and Firefox, and the GitHub Action DavidNiessen/readme-studio. Readme Studio is a private, non-commercial open-source project; its source code is public on GitHub.

3. Website hosting (GitHub Pages)

The website is served by GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA. When you visit it, GitHub processes technically necessary data, in particular your IP address, the date and time, the address requested, the amount of data transferred, the referrer and details of your browser and operating system, to deliver the pages and keep the service secure. I have no access to these logs.

The legal basis is Art. 6(1)(f) GDPR; my legitimate interest is serving the website securely and reliably. Data may be transferred to the USA. GitHub is certified under the EU-US Data Privacy Framework, and the transfer relies on the European Commission's adequacy decision (Art. 45 GDPR). How long GitHub keeps the data is set out in the GitHub Privacy Statement.

4. Storage in your browser

The studio and the extension store the following only on your device, in your browser's or the extension's local storage:

  • Your designs, including unsaved changes per repository.
  • Preferences, for example light or dark mode, the editor view used last, recently used colours and the save method you prefer.
  • A GitHub sign-in, if you give one: a personal access token you enter or, in the extension, the token from "Sign in with GitHub". It is used only to read and save the README design in your repositories and is sent only to GitHub (api.github.com).
  • A pending edit (extension only): when you save through GitHub's own editor, the file's text is kept for up to 15 minutes so the extension can fill it into the editor.

None of this is sent to me; I can neither see nor analyse it. Storing it on your device is strictly necessary to provide the features you explicitly ask for (§ 25(2)(2) TDDDG), so no consent is needed. It stays until you delete it: by signing out, by clearing the site's data in your browser, or by removing the extension.

5. Requests to third parties

When you use a feature that needs data, your browser fetches it directly from the provider. Like any web request, this gives the provider your IP address and the request itself (such as a GitHub username, repository name or place name); the provider's own privacy policy applies to what it does with them. These requests happen only when you use the feature (Art. 6(1)(f) GDPR; legitimate interest: providing the feature you asked for).

  • GitHub (github.com, api.github.com, raw.githubusercontent.com, avatars.githubusercontent.com; GitHub, Inc., USA): public profile and repository data for the preview, opening and importing a README or design, and saving your design when you ask. Privacy statement
  • npm, PyPI and crates.io (registry.npmjs.org, api.npmjs.org, pypi.org, pypistats.org, crates.io): only for project READMEs that name a package, for its version and download counts.
  • Open-Meteo (api.open-meteo.com, geocoding-api.open-meteo.com): only when you look up a place or use widgets that show local weather. Privacy notice

Some of these providers are located outside the EU, in particular in the USA.

6. Browser extension

The extension runs only on github.com. There it adds an "Edit README" button to repository pages, opens the studio over the page and, if you choose, fills GitHub's file editor with your design. It talks to nothing but GitHub, does not read or record the pages you visit, and keeps its data locally as described in section 4, without syncing between devices. It uses the storage permission for that local storage and host permissions for github.com, api.github.com and raw.githubusercontent.com.

7. GitHub Action

The Action runs in your own GitHub repository on GitHub's servers, with the permissions you give its workflow. It reads public data about your account or repository from GitHub and the package registries named in section 5, renders the images and writes them and your README to your repository. Nothing is sent to me. GitHub's processing is governed by your agreements with GitHub.

8. Contact by email and GitHub issues

If you email me, I process your email address and your message to answer you (Art. 6(1)(f) GDPR; legitimate interest: answering enquiries). I delete the message once it is dealt with, unless a legal retention duty applies. Posts in GitHub issues are public and governed by GitHub's terms.

9. Your rights

Within the limits of the law, you have the right to

  • access the data stored about you (Art. 15 GDPR),
  • rectification (Art. 16 GDPR) and erasure (Art. 17 GDPR),
  • restriction of processing (Art. 18 GDPR),
  • data portability (Art. 20 GDPR),
  • object to processing based on Art. 6(1)(f) GDPR on grounds relating to your particular situation (Art. 21 GDPR).

Write to support@niessen.dev. Since I receive no data about you except emails you send, your designs, settings and tokens are with you alone, and you can delete them at any time. Revoke GitHub access on GitHub under Settings → Applications, or Settings → Developer settings → Personal access tokens.

You also have the right to lodge a complaint with a data protection supervisory authority (Art. 77 GDPR). The authority responsible for me is the Berlin Commissioner for Data Protection and Freedom of Information (Berliner Beauftragte für Datenschutz und Informationsfreiheit), Alt-Moabit 59–61, 10555 Berlin, Germany, www.datenschutz-berlin.de.

10. Further information

  • There is no automated decision-making or profiling (Art. 22 GDPR).
  • You are not obliged to provide any data. Without a GitHub sign-in you can save through GitHub's editor or export the files.
  • Readme Studio is meant for GitHub users and is not directed at children.

11. Changes

If what Readme Studio does with data changes, I update this policy and the date at the top. Every version is public in the repository.
