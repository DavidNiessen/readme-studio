Readme Studio

Privacy policy

Last updated 26 November 2026

Readme Studio has no accounts, no servers of its own, no cookies, no analytics and no advertising. What you make stays in your browser and in your own GitHub repositories. This page explains exactly what is stored where and which services your browser talks to.

This policy covers the website at readme.niessen.dev (the studio and its documentation), the Readme Studio browser extension for Chrome and Firefox, and the Readme Studio GitHub Action. Readme Studio is an open-source project by David Nießen; its source code is public at github.com/DavidNiessen/readme-studio.

What we collect

Nothing. Readme Studio does not collect, receive, sell or share personal data. The developer has no way to see who uses it or what they make with it.

What is stored on your device

The studio and the extension keep the following in your own browser's storage. It never leaves your device unless you save it to GitHub yourself.

  • Your designs: the README designs you work on, including unsaved changes per repository.
  • Preferences: for example light or dark mode, the editor view you used last, recently used colours and the save method you prefer.
  • A GitHub sign-in, if you give one: a personal access token you enter, or, in the extension, the token from "Sign in with GitHub". It is used only to read and save the README design in your repositories and is sent only to GitHub (api.github.com). Sign out to remove it.
  • A pending edit (extension only): when you save through GitHub's own editor, the file's text is kept for up to 15 minutes so the extension can fill it into the editor page.

You can delete all of this at any time by clearing the site's data in your browser, or by removing the extension.

Services your browser contacts

When you use a feature that needs data, your browser asks the service that has it directly. Like any web request, this shares your IP address and the request itself (such as a GitHub username or repository name) with that service, under its own privacy policy:

  • GitHub (github.com, api.github.com, raw.githubusercontent.com, avatars.githubusercontent.com): to load public profile and repository data for the preview, to open or import a repository's README and design, and to save your design when you ask. The website itself is hosted on GitHub Pages, which may log visits for security. See the GitHub Privacy Statement.
  • npm, PyPI and crates.io: only for project READMEs that name a package, to show its version and download counts.
  • Open-Meteo: only when you look up a city or use widgets that show local weather, to find its coordinates and weather.

The browser extension

The extension runs only on github.com. There it adds an "Edit README" button to repository pages, opens the studio over the page, and, if you choose, fills GitHub's file editor with your design. It talks to nothing but GitHub, does not read or record the pages you visit, and keeps its data in the extension's local storage as described above. It does not sync that data across devices.

The GitHub Action

The Action runs in your own repository, on GitHub's servers, with the permissions you give its workflow. It reads public data about your account or repository from GitHub and the package registries named above, renders the images, and writes them and your README to your repository. Nothing is sent to the developer of Readme Studio.

Your choices

  • Use the studio without signing in: saving through GitHub's own editor or exporting the files needs no token.
  • Prefer a fine-grained personal access token limited to the repositories you design, with an expiry date.
  • Revoke access at any time on GitHub: Settings → Applications for "Sign in with GitHub", or Settings → Developer settings → Personal access tokens for tokens you created.

Because the developer holds no data about you, there is nothing to request, correct or delete on our side; everything lives in your browser and your GitHub account, which you control.

Children

Readme Studio is a tool for GitHub users and follows GitHub's own age requirements. It is not directed at children.

Changes

If what Readme Studio does with data changes, this page changes with it, and the date at the top is updated. Its full history is public in the repository.
